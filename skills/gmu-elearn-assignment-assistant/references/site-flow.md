# 站点流程

## 输入解析
- 优先提取 `《课程名》` 作为 `course_name`。
- 如果用户还给了具体作业名，把它当作 `assignment_name`，优先精确匹配。
- 若课程名无法稳定提取，再向用户确认一次；不要在多个候选课程之间自行猜测。

## 阶段 A：打开平台
- 打开或切到 Chrome。
- 默认首先访问 `https://i.chaoxing.com`，等待页面及登录重定向完成。
- 未登录时，该入口会跳转到超星学习通登录页面。跟随实际跳转，不手工拼接含临时参数的登录地址。
- 已登录时，从当前落地页继续进入课程列表。
- 用户明确提供其他课程直达链接或学校专属入口时，按该入口处理；默认入口不依赖任何学校书签。
- 根据实际页面识别登录表单、`登录` 按钮、课程入口或用户头像。

## 阶段 B：登录
- 若已经处于登录状态，直接跳过。
- 若出现登录页并且账号、密码已被浏览器自动填充，直接点击 `登录`。
- 若字段未填充，先点击账号框和密码框，观察是否出现浏览器保存的补全选项。
- 没有可用的已保存凭据时，让用户在网页上完成登录，不猜测账号或密码。
- 以页面显示的手机号／超星号等登录方式为准。若需选择学校、机构或身份，仅使用用户明确提供或页面已能确定的信息；无法确定时先询问用户。
- 这个 skill 默认不额外征求登录确认；用户既然已经明确要求处理该平台作业，就允许使用本机已保存凭据完成登录。
- 需要用户完成的登录步骤包括：
  - 没有可用的已保存凭据
  - 无法确定页面要求的学校、机构或身份
  - 验证码
  - 短信验证
  - 扫码确认
  - MFA
  - 异地登录/设备确认

## 阶段 C：进入课程列表
- 根据当前页面查找 `课程`、`我的课程`、`我学的课` 或等价入口；若显示 `学习空间`，可先进入该页面再寻找课程列表。
- 按当前账号与平台版本的实际界面导航，不要求出现某所学校的专属菜单。
- 有课程搜索框时优先搜索 `course_name`；否则查看课程卡片、分页或筛选结果。
- 只有一个明显匹配课程时可直接进入。
- 若有多个近似课程名，必须停下来让用户选择。

## 阶段 D：进入作业页
- 进入课程主页后，找到 `作业` 菜单或标签并点击，以实际布局为准。
- 在作业列表优先识别这些状态文字：
  - `未交`
  - `未完成`
  - `已完成`
  - `剩余时间`
- 若提供了 `assignment_name`，按名称精确或高相似度匹配。
- 若未提供 `assignment_name`，优先打开第一个 `未交` / `未完成` 作业。
- 优先依据状态文字，不依赖蓝色标记。状态文字不明确时，可结合 `剩余时间`、`可作答` 等信号判断；`未评分` 本身不等于未交，无法确定时先核对作业详情。

## 页面识别提示
- 登录页：手机号／超星号、学习通密码、`登录`、验证码或扫码登录入口。
- 登录后首页：课程模块、头像，以及实际显示的 `课程`、`我的课程` 或 `学习空间` 入口。
- 课程列表：`我的课程` / `我学的课`、课程搜索框、课程卡片标题。
- 课程主页：菜单或标签中的 `作业`。
- 作业列表：`未交` / `未完成` 状态文字、剩余时间、作业标题。
- 作业详情：题干、题号、附件、作答框、`提交` 按钮。

## 匹配与停止规则
- 课程匹配不唯一时停止。
- 作业名匹配不唯一时停止。
- 页面结构明显异常或站点跳转到无关页面时停止。
- 从 `i.chaoxing.com` 到超星登录页的正常重定向属于预期流程。
