# 站点流程

## 输入解析
- 优先提取 `《课程名》` 作为 `course_name`。
- 如果用户还给了具体作业名，把它当作 `assignment_name`，优先精确匹配。
- 若课程名无法稳定提取，再向用户确认一次；不要在多个候选课程之间自行猜测。

## 阶段 A：打开平台
- 打开或切到 Chrome。
- 优先点击书签栏中的 `广州医科大学e学中心`。
- 若书签不可见或点击失败，优先查找已打开的同站点标签页。
- 进入首页后，优先识别 `登录` 按钮、平台首页模块、或用户头像。

## 阶段 B：登录
- 若已经处于登录状态，直接跳过。
- 若出现登录页并且账号、密码已被浏览器自动填充，直接点击 `登录`。
- 若字段未填充，先点击账号框和密码框，观察是否出现浏览器保存的补全选项。
- 这个 skill 默认不额外征求登录确认；用户既然已经明确要求处理该平台作业，就允许使用本机已保存凭据完成登录。
- 仅在以下情况暂停：
  - 验证码
  - 短信验证
  - 扫码确认
  - MFA
  - 异地登录/设备确认

## 阶段 C：进入学习空间
- 在首页匹配 `学习空间` 并点击。
- 进入 `我学的课` 或等价课程列表页。
- 优先使用页面搜索框搜索 `course_name`。
- 只有一个明显匹配课程时可直接进入。
- 若有多个近似课程名，必须停下来让用户选择。

## 阶段 D：进入作业页
- 进入课程主页后，查看左侧菜单并点击 `作业`。
- 在作业列表优先识别这些状态文字：
  - `未交`
  - `未完成`
  - `已完成`
  - `剩余时间`
- 若提供了 `assignment_name`，按名称精确或高相似度匹配。
- 若未提供 `assignment_name`，优先打开第一个蓝色 `未交` / `未完成` 作业。
- 若蓝色状态不明显，可结合 `剩余时间`、`可作答`、`未评分` 等信号综合判断。

## 页面识别提示
- 平台首页：`登录`、`学习空间`、课程模块、头像。
- 学习空间：`我学的课`、课程搜索框、课程卡片标题。
- 课程主页：左侧菜单中的 `作业`。
- 作业列表：蓝色 `未交` / `未完成`、剩余时间、作业标题。
- 作业详情：题干、题号、附件、作答框、`提交` 按钮。

## 匹配与停止规则
- 课程匹配不唯一时停止。
- 作业名匹配不唯一时停止。
- 页面结构明显异常或站点跳转到无关页面时停止。
