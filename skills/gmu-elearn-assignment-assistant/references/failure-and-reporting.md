# 异常处理与汇报

## 找不到按钮
- 优先按页面可见文字匹配：
  - `登录`
  - `课程` / `我的课程` / `我学的课` / `学习空间`（以当前页面为准）
  - `作业`
  - `未交`
  - `未完成`
- 若不可见，滚动页面后重试。
- 若仍失败，截图并向用户说明卡在哪一步。

## 找不到课程
- 先用课程列表页搜索框搜索课程名。
- 若无结果，返回列表页做人眼近似匹配。
- 仍找不到时，停止并请求用户提供更准确课程名。

## 找不到作业
- 检查筛选、分页、折叠区、弹窗遮挡。
- 若用户指定了作业名但存在多个相近项，暂停并请求确认。
- 若没有任何未交作业，直接汇报“当前课程下未发现未交/未完成作业”。

## 页面加载慢或异常
- 等待骨架屏、空白页、延迟加载完成。
- 若弹窗遮挡，先关闭无关弹窗。
- 若页面长期空白或脚本异常，刷新一次；仍失败则停止。

## 必须暂停的情况
- 不会写或题意无法判断
- 在需要 JavaScript 回退时，按编辑器策略尝试后仍无法填写，或当前环境没有可用的页面 JavaScript 执行能力；说明具体阻碍。页面提示“不可粘贴，只可录入”时，应先执行 JavaScript 回退流程
- 课程或作业匹配不唯一
- 需要覆盖用户现有草稿
- 你无法继续完成任务
- 出现最终提交相关确认
- 出现验证码、MFA、短信、扫码等身份验证，或没有可用的已保存凭据，需要用户在网页上完成登录
- 登录要求选择学校、机构或身份，但页面与用户说明均不足以确定
- 当前没有符合复核模型要求的可用子代理、无法确认实际模型，或复核失败、缺少必要材料且无法补齐；保留草稿并如实汇报。未指定模型时可在合格模型范围内选择，不能自动降到范围外

```markdown

- 已登录：{是/否}
- 已进入课程：{课程名}

- 已独立读取题目并生成答案草稿：{是/否}
- 已填入作答框：{是/否}
- 已暂时保存：{是/否}
- 已启动独立复核子代理：{是/否}
- 当前 CLI：{Codex / Claude Code / Kimi Code / OpenCode / 其他}
- 子代理实际模型：{提供商、完整模型 ID 与版本 / 未能确认 / 未成功启动}
- 是否符合复核模型要求：{是/否/无法确认}
- 子代理质量评估：{通过/需要修改/材料不足/未完成}
- 如子代理要求修改，是否已替换并再次暂时保存：{是/否/不适用}
- 子代理是否已确认最终保存版本：{是/否/待复核}

- 核心要求：{按页面提取}
- 题型判断：{简答/案例分析/论述/选择混合等}

### 建议作答框架

1. {框架点1}
2. {框架点2}

4. {框架点4}

### 需要用户补充

- {页面缺失的信息}
- {个性化表述或老师口径}

### 风险与不确定

- 是否完成：{已完成/部分完成/未完成}
- 是否有不确定：{无/有}
- 不确定点：{列出}
- 是否误触提交：{否/疑似/是}
- 暂时保存是否成功：{是/否/不确定}

- 再检查术语、数字、专有名词是否准确

- 最后由用户自行决定是否提交
```
